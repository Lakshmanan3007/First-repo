# TRACE v0.1.0

Initial MVP Release

"Every Task Leaves a Trace."

## Overview

TRACE is a time-aware accountability system designed around a simple philosophy:

Every task progresses through a lifecycle and leaves a permanent record of its outcome.

This initial MVP release introduces the core foundation of TRACE, including task management, task state transitions, scheduling, activity tracking, and local-first productivity workflows.

---

## Features

### Core Task Management

* Create and manage tasks
* Optional start times
* Required deadlines
* Task descriptions and notes
* Priority levels
* Project organization
* Tags support

### Task Lifecycle System

Tasks move through structured states:

* Upcoming
* Current
* Completed
* Failed

Tasks automatically transition based on time and user actions.

### Schedule View

* Date-based task navigation
* Timeline-oriented planning
* Upcoming task visibility

### Activity Tracking

* Task activity monitoring
* Completion history
* Failure history
* State transition tracking

### Search

Search tasks using:

* Task titles
* Tags
* Projects

### Notifications

* Task activation alerts
* Deadline reminders

### Local-First Storage

* No account required
* Offline functionality
* Local device storage

### Themes

* Light Theme
* Dark Theme

---

## Design Philosophy

TRACE focuses on:

* Accountability
* Simplicity
* Structured productivity
* Preserved task history
* Minimal distraction

Every task eventually reaches an outcome:

Upcoming → Current → Completed / Failed
